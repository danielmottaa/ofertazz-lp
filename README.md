# Ofertazz Landing Page

Site estatico em portugues, sem instalacao ou build. Abra `index.html` no navegador.

## Conteudo

- Apresentacao do Ofertazz e das funcionalidades do MVP.
- Demonstracao interativa de ofertas, listas e colaboracao.
- Simulacao ajustavel de economia potencial, sem promessa de resultado.
- Animacoes no scroll com respeito a preferencia de movimento reduzido.
- Menu mobile, perguntas frequentes e compartilhamento nativo em HTTPS.

## Publicar

Hospede esta pasta em qualquer hospedagem estatica com HTTPS. Nao ha backend, formulario, coleta de dados ou cadastro de interessados. Os links das lojas nao foram inventados: adicione-os quando houver publicacao oficial. A acao de compartilhar funciona com a URL publicada; em arquivo local, informa que o site precisa ser publicado.
